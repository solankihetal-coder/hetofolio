# Visual Gallery Assets

Keep visual-work assets grouped by their actual presentation category:

- `branding/` — logos and identity work
- `social/` — social-media creatives and square promotional posts
- `graphics/` — banners and wider promotional graphics
- `print/` — business cards and other print material

The gallery page uses CSS columns for a true masonry layout. Keep each asset's natural proportion and use the `format` field in `data/gallery-data.js` when an item needs a specific presentation ratio.
